# Changelog

The extension's version follows Desk Arcade's: each Desk Arcade release packages it again.

## 1.8.6

- First release. Tasks and debug sessions light a lane on Desk Arcade's scoreboard: running with a timer, then passed
  or failed with the exit code, or cleared when stopped by hand.
- A status-bar button shows or hides the overlay.
- Commands: Play while it builds, Show or hide the overlay, Next game.
- Settings for tasks and debug sessions, which tasks count, a lane name prefix, the `--profile` copy to talk to and
  where Desk Arcade is installed.
- English, Russian and Uzbek.
